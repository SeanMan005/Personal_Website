## The project behind it

The site showcases an AI knowledge base built for structured retrieval:

- **508 documents (520K words)** indexed by a **7-table SQLite schema**
- **941 category links** across 36 topics and 120 sub-categories, with 83% of documents linked to more than one category
- A **retrieval-augmented generation (RAG)** workflow that pulls relevant documents as grounded context for an LLM
- A **multi-agent pipeline** that turns research documents into labeled diagrams
- A site generator that renders a 540+ page catalog from a single data file
