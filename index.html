The Architectural Axis

Live site

Architecture states what a system must do; design states how. The two directions on that axis are not inverses — going up is subtraction and costs nothing, coming down is exclusion and can only be bought with evidence. Three mechanisms: direction, price, substance.

The Motivation–Cognition Loop

Live site

Cognition supplies the shape — one mismatch, resolved either by acting on the world or by updating the pattern. Motivation supplies only the rate: drive is directionless force that sets how many mismatches run per cycle, never where they aim. Run the loop hot and the drive is spent; only the patterns compound.
