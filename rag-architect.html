The Architect

A full-stack retrieval-augmented research agent over a private corpus of 700,000 words of original systems theory. The corpus is too large to send to a model and no public model was trained on it, so 498 documents are split into 2,874 semantically indexed chunks in a vector database — each question retrieves only the five nearest passages and streams back a grounded answer in the theory's own vocabulary. Cost per question stays flat no matter how far the corpus grows.

Three tiers

Each tier owns one responsibility and keeps one secret from the tier in front of it: the browser never sees a key, and the model never sees a file name.

Tier 1 · Data

Indexing pipeline

ingest.py · Pinecone

  • Stable IDs. SHA-1 of source, page and chunk position within its own document, so adding a file never shifts another file's IDs.
  • Incremental. Existing IDs are fetched and skipped first, so a re-run costs nothing for unchanged text.
  • Rate-limit aware. Batches of 90 with a 60-second backoff on HTTP 429; the full corpus indexes unattended.
  • Long-path safe. Windows extended-length prefixes recovered 7 documents that Python had been dropping silently.
Tier 2 · Application

Retrieval & generation

server.py · FastAPI

  • Semantic search. The five chunks nearest in meaning rather than wording — a question about pricing can retrieve a passage about cost.
  • Stripped context. File names are removed before the excerpts reach the model, so it cannot cite a source it never received.
  • Streaming. NDJSON text deltas over the Messages API, with configurable model, reasoning effort and a server-side refusal fallback.
  • Typed errors. Auth, rate-limit, status and connection failures each become a sentence on screen instead of a crash.
Tier 3 · Presentation

Caption interface

index.html · no dependencies

  • One caption. The current answer fills the screen at 24–42 px; the thread lives in browser storage, not on the page.
  • Live render. Text appears as it generates, with a blinking cursor and a face that pulses faster while the agent is thinking.
  • Safe markdown. Every token is HTML-escaped before rendering, so model output cannot inject markup.
  • Keyboard-first. Enter sends, Shift+Enter breaks the line, Esc stops the reply.

What it answers

Live tests against the running index. The agent speaks as the theory rather than about documents — it states the idea, holds the coined terminology exact, and declines what the corpus does not cover.

In two sentences, what is structural density?

“Structural density is the accumulated product of a structure's two axes, scope and sampling density, built through recursive cycles of expansion and tightening. It is the total predictive and generative capacity of the structure…”

Material spread across four documents, compressed to the requested length.

What is the Apex Transduction Principle?

“…every complex adaptive system is a vertical transduction engine, and authority is the downward half of its refinement cycle… highest-grade compute and highest-grade abstract energy are the same quantity measured in two frames.”

A specific named principle retrieved whole, with its multi-part structure intact.

What is the capital of France?

“The theory does not address the capital of France.”

Closed mode — the agent stays inside the corpus instead of drifting into general knowledge.

What it cost to get right

The failures that only appear at corpus scale, and what each one forced into the design.

ProblemEvidenceFix
Silent data loss 491 documents indexed against 498 on disk, with no error raised Paths over 260 characters were being dropped by the directory walk; extended-length prefixes recovered all 7, verified at 498 / 498
Embedding rate limit A full re-index ended on HTTP 429 at the 250k-tokens-per-minute cap Detection plus a 60-second backoff; the last full run waited out 5 limits with no intervention
Duplicate vectors Adding one document shifted the IDs of every chunk after it IDs re-keyed to each chunk's position within its own document, plus a pre-upload existing-ID check
Source leakage Answers risked naming files the reader has no access to File names stripped from the context itself, not merely forbidden in the prompt; the response stream carries text events only
Key exposure Two paid APIs, one of them billed per token Keys read server-side from .env only, the server binds to 127.0.0.1 and serves two named files — GET /.env returns 404
